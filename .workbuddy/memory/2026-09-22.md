### 关键技术事实（后续任务会用到）

- `peniko 0.6` 没有根级 `Color` 定义，实为 `pub type Color = color::AlphaColor<color::Srgb>`。
- `AlphaColor` 只派生 `Clone/Copy/Debug`，**没有 `PartialEq`** → `Background` 不得派生 `PartialEq`；颜色比对一律用 `to_rgba8()`（`Rgba8` 有 `PartialEq/Eq`）。
- `Color::from_rgba8(r,g,b,a)` 是 const fn，可用于 `const` 常量。
