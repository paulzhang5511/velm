## T6 layout 模块完成（手写 LinearLayout 测量）

- 新增 `crates/velm/src/layout/{mod,measure}.rs` + `crates/velm/tests/layout.rs`；`lib.rs` 无条件 `pub mod layout`。
- 16 个 host 单测全绿（累计 37）；三目标 clippy `-D warnings` + fmt 全绿。
- 修正 docs 两个缺陷：容器 WrapContent = 子节点「主轴求和 / 交叉轴取最大」（非 MatchParent）；margin 四向既偏移位置也扣减可用尺寸。

### 算法要点（T7/T11/T13 会依赖）

- 两遍 O(n)：`measure` 求宽高写 `computed_rect`（x/y 置 0）→ `place` 写绝对坐标。容器 WrapContent 依赖子节点尺寸，故求尺寸必须先于定位；两遍各遍历一次全树。
- 关键坐标约定：`place` 的 `content_x/content_y` 是**父节点内容区原点**，子节点 rect = 父原点 + 主轴游标 + 自身 margin。v1 无 padding。
- 文本度量隔离为 `pub fn estimate_text_width(text, text_size_px)`（chars * size * 0.6），P1 换 skrifa advance 时只改这一处。
- 根节点可用区 = 整窗尺寸 - 根自身 margin（否则 MatchParent 根带 margin 会溢出）。
- v1 限制：WrapContent 容器内的 MatchParent 子节点按上界一次求值，不实现 Android 二次 measure。

## T7 hit_test 模块完成（DFS 命中测试）

- 新增 `crates/velm/src/engine/hit_test.rs` + `crates/velm/tests/hit_test.rs`；`lib.rs` 改无条件 `pub mod engine`，`engine/mod.rs` 内只对 `activity_thread` 子模块 gate android（否则 hit_test 失去 host 可测性）。
- 15 个 host 单测全绿（累计 54 = T4 13 + T5 8 + T6 18 + T7 15）；三目标 clippy `-D warnings` + fmt 全绿。

### 语义决策（SPEC §7.5 已回写）

- 容器「回落」发生在子节点 `find_map` 之内：子节点及后代都不产生消息时继续探测更下层兄弟 → **未绑监听的容器对点击透明**，绑了监听的容器才拦下点击。两条回归用例钉住穿透/拦截。

### 教训（通用，值得复用）

- **density 类 bug 只在 density≠1 显现**：T7 的端到端用例（layout + hit_test 串联）暴露 T6 缺陷——margin 未乘 density，三处消费点（位置偏移 / 可用区扣减 / 主轴推进量）把 dp 当像素用。T6 单测全用 density=1，故完全没暴露。已统一收敛为 `margin_px(margin, density)`，并补两条 density=2 回归。
- **结论**：凡是 dp↔px 混用的模块，回归用例必须包含 density≠1 分支；跨模块端到端用例（layout→hit_test）比单模块用例更容易抓到这类单位错误。

## T8 app 契约 + 引擎状态机完成（Phase 1 收尾）

- 新增 `app/{mod,activity,state}.rs`、`engine/events.rs`、`tests/{state_machine,app}.rs`；`lib.rs` 加 `pub mod app`。
- 27 个新 host 单测（state_machine 17 + app 10），累计 **81**；host/aarch64/x86_64 三目标 clippy `-D warnings` + fmt 全绿；android 双 target build 通过。

### 结构决策（T12 接线时按此引用）

- 生命周期状态机在 **`engine::events`**（`EngineEvent` / `EngineAction` / `EngineState` / `step`），**不在** PLAN 原写的 `app::state`（那里放 `ActivityRuntime`）。理由：状态机管窗口/队列生命周期，属引擎层；放 app 会让 T12 写出 `use crate::app::state::EngineState` 的逆分层引用。
- 重绘用**标志位** `EngineState::take_draw_request()` 表达，没有 `EngineAction::Redraw`。窗口销毁时清除未消费标志。
- `WindowResized` 不携带 density（T3 回调只给宽高）→ 沿用旧值，禁止回落 1.0。
- `Quit` 先 `DestroySurface` → `DetachQueue` → `Exit`；置位后所有事件返回空动作集。
- `ActivityRuntime`：enqueue 与 drain 分离（保证一帧只因消息重建一次视图树，§7.7）；`on_touch_event` 返回 true = 已拦截，引擎跳过 hit-test。

### 踩坑

- `Intent<Message>` 的 Clone/Copy/Default/Debug 必须**手写**：derive 会给 `Message` 加约束，而 Intent 只有 `PhantomData`。
- 手写 Clone 返回 `Self::none()` 会触发 clippy `non_canonical_clone_impl`，应返回 `*self`。
- `EngineEvent` 含 `Viewport{density: f32}` → 只能派生 `PartialEq`，不能 `Eq`。

### 结构约定（T11/T13 按此接线）

- **渲染两层**：`render::scene`（视图树 → `DrawCommand{FillRect,Text}`，host 可测）+ `vello_renderer`（编码/present）。顺序契约：节点背景 → 自身文本 → 子节点（添加顺序）。零面积子树整体跳过。
- 文本**左对齐 + 垂直居中**，`centered_baseline(height, ascent, descent)`（ascent/descent 取正值；skrifa `descent` 为负，`FontFace::vertical_metrics` 取 abs）。
- `VelloRenderer::new(window, w, h, density)`：内部先 `configure_buffers(RGBA_8888)`，再用 `window.window_handle()/display_handle()` 的 raw 句柄调 `create_surface_unsafe`（T9 遗留验收项在此闭合）。
- surface 错误：`Outdated` 重配重试一次；`Lost` 丢弃本帧等窗口重建；`Timeout`/`Occluded` 跳过。每帧失败只告警。
- `resize` 用缓存的 `last_frame` 立即重画（重配后到下一帧之间会露未定义内容）。
- 删除 T2 spike 的 `render_frame()` 探针帧；**首帧必须由 T11 用 Activity 真实视图树产出**（T2 实证：不提交首帧则触摸不投递）。
