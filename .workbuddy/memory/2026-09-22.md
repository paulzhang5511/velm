### 关键技术事实（后续任务会用到）

- `peniko 0.6` 没有根级 `Color` 定义，实为 `pub type Color = color::AlphaColor<color::Srgb>`。
- `AlphaColor` 只派生 `Clone/Copy/Debug`，**没有 `PartialEq`** → `Background` 不得派生 `PartialEq`；颜色比对一律用 `to_rgba8()`（`Rgba8` 有 `PartialEq/Eq`）。
- `Color::from_rgba8(r,g,b,a)` 是 const fn，可用于 `const` 常量。

### 关键技术事实（补充）

- raw-ndk-sys 常量类型：`AMOTION_EVENT_ACTION_*` 为 **u32**（`_bindgen_ty_23 = c_uint`），`AINPUT_EVENT_TYPE_*` 也是 u32（`_bindgen_ty_20`）；`AInputEvent_getType` / `AMotionEvent_getAction` 返回 **i32**，需显式 `as i32` / `as u32` 转换。
- 手写常量与 NDK 绑定的漂移防护：`#[cfg(target_os = "android")] const _: () = { assert!(...) }` —— android 编译期求值，host 因 raw-ndk-sys 是 android-only 依赖而跳过。这个模式可复用到任何「host 手写常量 ↔ NDK 绑定」场景。
